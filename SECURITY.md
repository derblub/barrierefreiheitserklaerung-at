# Sicherheit

## Was hier ein Sicherheitsproblem ist

Die Vorlage ist Text, kein Programm. Ein Sicherheitsproblem wäre zum Beispiel ein Link, der auf eine fremde oder schädliche Seite führt, oder ein Platzhalter, der dazu verleitet, Zugangsdaten oder andere vertrauliche Angaben in eine öffentliche Erklärung zu schreiben.

Ein Fehler in einer rechtlichen Aussage ist kein Sicherheitsproblem. Dafür bitte ein [Issue](https://github.com/derblub/barrierefreiheitserklaerung-at/issues/new/choose) öffnen.

## Melden

Bitte kein öffentliches Issue. Melde es privat über die [Sicherheitsmeldung von GitHub](https://github.com/derblub/barrierefreiheitserklaerung-at/security/advisories/new) oder per E-Mail an [daniel@pushingpixels.at](mailto:daniel@pushingpixels.at).

Ich antworte innerhalb von fünf Werktagen. Sobald die Korrektur erschienen ist, nenne ich die Meldung in `CHANGELOG.md`, außer du möchtest das nicht.
